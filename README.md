Projeto de CRUD completo feito com React Native e banco de dados Firebase integrado

🎯O foco desse projeto é treinar as principais ferramentas do JavaScript e aprender a implementar banco de dados nos projetos
° Aplicativo contém tela de Login simples, sem autenticação ou cadastro real de email
° o Aplicativo contém o CRUD completo, para ler dados, excluir dados, cadastrar dados e atualizar dados salvos no banco de dados
